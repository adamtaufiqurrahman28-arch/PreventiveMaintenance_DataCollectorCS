# CrowdStrike API Scopes

Aktifkan hanya:

| Service | Permission | Kegunaan |
|---|---|---|
| Hosts | Read | Detail host untuk Lampiran A |
| Prevention Policies | Read | Policy, settings, dan members untuk Lampiran B |
| Alerts | Read | Detection Alerts API untuk Lampiran C |

Tidak diperlukan:

- NGSIEM
- Alerts Write
- Hosts Write
- Prevention Policies Write
- RTR
